ODATA QUERY BUILDER
===================

Modules: GraphApi.OData, GraphApi.OData.Filter


GRAPHAPI.ODATA
--------------

Functional builder for OData query parameters ($select, $filter, $expand,
$top, $skip, $orderby, $count, $search).

Struct type:

    %GraphApi.OData{
      select: [String.t()] | nil,
      filter: String.t() | nil,
      expand: [String.t()] | nil,
      top: pos_integer() | nil,
      skip: non_neg_integer() | nil,
      orderby: String.t() | nil,
      count: boolean() | nil,
      search: String.t() | nil
    }

Functions:

  OData.new()
  @spec new() :: OData.t()
  Creates a new empty OData query builder.

  OData.select(query, fields)
  @spec select(OData.t(), [String.t()]) :: OData.t()
  Sets $select fields.

  OData.filter(query, expression)
  @spec filter(OData.t(), String.t() | Filter.t()) :: OData.t()
  Sets $filter. Accepts raw string or Filter struct.

  OData.filter(query, schema, conditions)
  @spec filter(OData.t(), module(), keyword()) :: OData.t()
  Sets $filter using schema module + keyword conditions.
  Snake_case keys are auto-converted to camelCase via schema.
  Multiple conditions are AND-ed with eq operator.

  OData.expand(query, fields)
  @spec expand(OData.t(), [String.t()]) :: OData.t()
  Sets $expand relationships.

  OData.top(query, n)
  @spec top(OData.t(), pos_integer()) :: OData.t()
  Sets $top (page size).

  OData.skip(query, n)
  @spec skip(OData.t(), non_neg_integer()) :: OData.t()
  Sets $skip (offset).

  OData.orderby(query, expression)
  @spec orderby(OData.t(), String.t()) :: OData.t()
  Sets $orderby expression.

  OData.count(query)
  @spec count(OData.t()) :: OData.t()
  Sets $count to true.

  OData.search(query, expression)
  @spec search(OData.t(), String.t()) :: OData.t()
  Sets $search expression.

  OData.to_params(query)
  @spec to_params(OData.t()) :: map()
  Converts to query parameter map. Only includes non-nil params.
  Lists joined with commas, booleans to strings.


USAGE WITH RESOURCE FUNCTIONS
-----------------------------

Pass via the :query option:

    alias GraphApi.OData

    query = OData.new()
      |> OData.select(["displayName", "mail", "id"])
      |> OData.filter("department eq 'Engineering'")
      |> OData.top(25)
      |> OData.orderby("displayName")

    {:ok, response} = GraphApi.Users.list(query: query)

    # to_params output:
    # %{
    #   "$select" => "displayName,mail,id",
    #   "$filter" => "department eq 'Engineering'",
    #   "$top" => "25",
    #   "$orderby" => "displayName"
    # }


GRAPHAPI.ODATA.FILTER
---------------------

Schema-aware OData filter builder. Translates snake_case Elixir field
names to camelCase API field names using schema module field mappings.

Struct type:

    %GraphApi.OData.Filter{
      schema: module(),
      clauses: [{:and | :or, atom(), operator(), term()}]
    }

Supported operators:
  :eq            - equality
  :ne            - inequality
  :gt            - greater than
  :lt            - less than
  :ge            - greater than or equal
  :le            - less than or equal
  :starts_with   - startsWith() function
  :ends_with     - endsWith() function
  :contains      - contains() function
  :in            - collection membership (value is a list)
  :is_nil        - null check (true => "eq null", false => "ne null")

Functions:

  Filter.new(schema)
  @spec new(module()) :: Filter.t()
  Creates a new filter builder for the given schema module.

  Filter.where(filter, field, op, value)
  @spec where(Filter.t(), atom(), operator(), term()) :: Filter.t()
  Adds an AND condition.

  Filter.or_where(filter, field, op, value)
  @spec or_where(Filter.t(), atom(), operator(), term()) :: Filter.t()
  Adds an OR condition.

  Filter.to_string(filter)
  @spec to_string(Filter.t()) :: String.t()
  Converts to OData filter string.

  Filter.from_keywords(schema, conditions)
  @spec from_keywords(module(), keyword()) :: String.t()
  Builds filter string from keyword conditions (all AND-ed with eq).
  Used internally by OData.filter/3.


SIMPLE KEYWORD SYNTAX
---------------------

For equality conditions combined with AND:

    alias GraphApi.Schema.User

    OData.new()
    |> OData.filter(User, department: "Engineering", account_enabled: true)
    # => $filter=department eq 'Engineering' and accountEnabled eq true


BUILDER SYNTAX
--------------

For complex filters with different operators:

    alias GraphApi.OData.Filter
    alias GraphApi.Schema.User

    filter =
      Filter.new(User)
      |> Filter.where(:display_name, :starts_with, "A")
      |> Filter.where(:account_enabled, :eq, true)
      |> Filter.or_where(:department, :eq, "Sales")

    OData.new() |> OData.filter(filter)
    # => $filter=startsWith(displayName,'A') and accountEnabled eq true or department eq 'Sales'


RAW STRING FILTER
-----------------

For any OData filter expression not covered by the builder:

    OData.new() |> OData.filter("startsWith(displayName, 'A')")


VALUE ENCODING
--------------

The filter builder automatically encodes values:
  nil          => null
  true/false   => true/false
  integers     => as-is
  floats       => as-is
  strings      => single-quoted, with ' escaped to ''

Collection membership (:in operator):

    Filter.new(User)
    |> Filter.where(:department, :in, ["Engineering", "Sales"])
    # => department in ('Engineering','Sales')


SCHEMA FIELD MAPPING
--------------------

Schema modules provide a __field_mapping__/0 function that maps
camelCase API names to snake_case Elixir atoms:

    GraphApi.Schema.User.__field_mapping__()
    # => %{"displayName" => :display_name, "accountEnabled" => :account_enabled, ...}

The Filter builder reverses this mapping to convert snake_case field
names back to camelCase for the OData expression.

If a field is not found in the schema, an ArgumentError is raised.
