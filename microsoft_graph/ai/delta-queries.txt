DELTA QUERIES
=============

Module: GraphApi.Delta

Delta queries track incremental changes to resources. Instead of fetching
the full dataset every time, you get only what changed since your last sync.


HOW IT WORKS
------------

1. Initial sync: Call Delta.query with a resource path.
   Returns all current items + a delta_link for future syncs.

2. Incremental sync: Call Delta.query with the stored delta_link.
   Returns only changed items (created, updated, deleted).

3. Deleted items have an "@removed" property:
   %{"id" => "abc", "@removed" => %{"reason" => "changed"}}


DELTA PAGE TYPE
---------------

    %{
      items: [map()],               # List of items
      delta_link: String.t() | nil,  # URL for next sync (present on last page)
      next_link: String.t() | nil    # URL for next page (present on multi-page results)
    }


FUNCTIONS
---------

  GraphApi.Delta.query(path_or_link, opts \\ [])
  @spec query(String.t(), keyword()) :: {:ok, delta_page()} | {:error, term()}
  Performs a delta query and returns a single page.
  Accepts a relative path (e.g., "/users/delta") for initial sync,
  or a full deltaLink/nextLink URL for subsequent pages.
  Options: :client, :query, :access_token, :api_version, :as

  GraphApi.Delta.collect_all(path_or_link, opts \\ [])
  @spec collect_all(String.t(), keyword()) :: {:ok, delta_page()} | {:error, term()}
  Collects all pages into a single result.
  Follows @odata.nextLink until a deltaLink is received.
  Returns all accumulated items plus the final delta_link.

  GraphApi.Delta.stream(first_page, opts \\ [])
  @spec stream(delta_page(), keyword()) :: Enumerable.t()
  Creates a lazy Stream that yields items from all pages.
  Follows @odata.nextLink automatically.
  Takes the first_page result from Delta.query.
  Options: :client, :access_token


SUPPORTED RESOURCES
-------------------

  /users/delta
  /groups/delta
  /groups/{id}/members/delta
  /users/{id}/messages/delta (or /me/messages/delta)
  /users/{id}/mailFolders/{id}/messages/delta
  /users/{id}/events/delta (or /me/events/delta)
  /drives/{id}/root/delta


PER-RESOURCE SHORTCUTS
----------------------

Each resource module provides delta convenience functions:

  GraphApi.Users.delta(opts \\ [])
  GET /users/delta

  GraphApi.Groups.delta(opts \\ [])
  GET /groups/delta

  GraphApi.Groups.members_delta(group_id, opts \\ [])
  GET /groups/{group_id}/members/delta

  GraphApi.Mail.messages_delta(user_id, opts \\ [])
  GET /users/{user_id}/messages/delta

  GraphApi.Mail.folder_messages_delta(user_id, folder_id, opts \\ [])
  GET /users/{user_id}/mailFolders/{folder_id}/messages/delta

  GraphApi.Calendar.events_delta(user_id, opts \\ [])
  GET /users/{user_id}/events/delta

  GraphApi.Files.drive_delta(drive_id, opts \\ [])
  GET /drives/{drive_id}/root/delta

Each also has a _query variant for batch requests.


INITIAL SYNC EXAMPLE
--------------------

    {:ok, page} = GraphApi.Delta.query("/users/delta", client: client)
    # page.items => [all current users]
    # page.delta_link => "https://graph...?$deltatoken=..."

    # Store delta_link somewhere persistent (database, ETS, etc.)
    save_delta_link(page.delta_link)


INCREMENTAL SYNC EXAMPLE
-------------------------

    stored_link = load_delta_link()
    {:ok, changes} = GraphApi.Delta.query(stored_link, client: client)

    for item <- changes.items do
      case item do
        %{"@removed" => %{"reason" => _reason}} ->
          delete_from_local_store(item["id"])
        user ->
          upsert_local_store(user)
      end
    end

    save_delta_link(changes.delta_link)


COLLECT ALL PAGES
-----------------

For initial syncs spanning multiple pages:

    {:ok, result} = GraphApi.Delta.collect_all("/users/delta", client: client)
    # result.items => all items across all pages
    # result.delta_link => final delta link


LAZY STREAMING
--------------

Stream items without loading everything into memory:

    {:ok, first_page} = GraphApi.Delta.query("/users/delta", client: client)

    first_page
    |> GraphApi.Delta.stream(client: client)
    |> Stream.filter(fn item -> item["@removed"] == nil end)
    |> Enum.each(&process_user/1)


SCHEMA CASTING WITH DELTA
--------------------------

Delta queries support :as for casting. Deleted items (with @removed)
are kept as raw maps:

    {:ok, changes} = GraphApi.Delta.query(delta_link,
      client: client,
      as: GraphApi.Schema.User
    )

    Enum.each(changes.items, fn
      %GraphApi.Schema.User{} = user ->
        IO.puts("Updated: #{user.display_name}")

      %{"@removed" => _} = removed ->
        IO.puts("Deleted: #{removed["id"]}")
    end)


WITH ODATA QUERY
----------------

    query = OData.new() |> OData.select(["id", "displayName"]) |> OData.top(100)
    {:ok, page} = GraphApi.Delta.query("/users/delta", client: client, query: query)
