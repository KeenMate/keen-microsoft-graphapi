AUTHENTICATION
==============

Modules: GraphApi.Auth, GraphApi.Auth.Delegated, GraphApi.TokenStore


TWO AUTHENTICATION MODES
-------------------------

1. App-only (client credentials) - for daemon/service apps
   - Configure once, tokens managed automatically by TokenStore
   - No user interaction needed

2. Delegated (authorization code) - for user-facing apps
   - OAuth 2.0 authorization code flow
   - Pass access_token per request


APP-ONLY AUTHENTICATION (CLIENT CREDENTIALS)
---------------------------------------------

Module: GraphApi.Auth

Acquires tokens by POSTing to:
  https://login.microsoftonline.com/{tenant}/oauth2/v2.0/token

  GraphApi.Auth.acquire_token(config)
  @spec acquire_token(GraphApi.Config.t()) :: {:ok, token_response()} | {:error, AuthError.t()}

  Returns:
    %{access_token: String.t(), expires_in: integer(), acquired_at: integer()}

  GraphApi.Auth.token_expired?(token, buffer_seconds \\ 300)
  @spec token_expired?(token_response(), integer()) :: boolean()

  Default buffer is 300 seconds (5 minutes) for proactive refresh.

Setup:

    config :keen_microsoft_graphapi, :config,
      tenant_id: System.fetch_env!("AZURE_TENANT_ID"),
      client_id: System.fetch_env!("AZURE_CLIENT_ID"),
      client_secret: System.fetch_env!("AZURE_CLIENT_SECRET")

    # Then just call resource modules - auth is automatic
    {:ok, users} = GraphApi.Users.list()


TOKEN STORE
-----------

Module: GraphApi.TokenStore

GenServer that caches OAuth tokens keyed by {tenant_id, client_id}.
Started automatically by the application supervisor.

  GraphApi.TokenStore.get_token(config, server \\ GraphApi.TokenStore)
  @spec get_token(GraphApi.Config.t(), GenServer.server()) :: {:ok, String.t()} | {:error, term()}

Behavior:
- If cached token is valid, returns it immediately
- If expired or missing, acquires a new token synchronously
- Proactively schedules refresh before expiry (expires_in - 300 seconds)
- On refresh failure, retries after 30 seconds

You rarely need to interact with TokenStore directly. The Auth middleware
calls it automatically when a client has a config but no per-request access_token.


DELEGATED AUTHENTICATION (OAUTH AUTHORIZATION CODE FLOW)
---------------------------------------------------------

Module: GraphApi.Auth.Delegated

For accessing resources on behalf of a signed-in user.

STEP 1: Build authorize URL

  GraphApi.Auth.Delegated.authorize_url(opts)
  @spec authorize_url(keyword()) :: String.t()

  Required options:
    :tenant_id    - Azure AD tenant ID (or "common" for multi-tenant)
    :client_id    - Application (client) ID
    :redirect_uri - URL to redirect back after login
    :scope        - Space-separated permissions (e.g., "User.Read Mail.Read")

  Optional options:
    :state         - CSRF token (strongly recommended)
    :response_type - Default "code"
    :response_mode - Default "query"
    :prompt        - "login", "consent", "select_account", or "none"

  Example:

    url = GraphApi.Auth.Delegated.authorize_url(
      tenant_id: "your-tenant-id",
      client_id: "your-client-id",
      redirect_uri: "http://localhost:4000/auth/callback",
      scope: "User.Read Mail.Read offline_access",
      state: generate_csrf_token()
    )
    # Redirect user to this URL

STEP 2: Exchange authorization code for tokens

  GraphApi.Auth.Delegated.exchange_code(opts)
  @spec exchange_code(keyword()) :: {:ok, token_response()} | {:error, AuthError.t()}

  Required options:
    :tenant_id     - Azure AD tenant ID
    :client_id     - Application (client) ID
    :client_secret - Application client secret
    :code          - Authorization code from callback
    :redirect_uri  - Must match the one used in authorize_url

  Optional options:
    :scope - Scope string (defaults to scope granted)

  Returns:
    %{access_token: String.t(), refresh_token: String.t() | nil,
      expires_in: integer(), scope: String.t() | nil, token_type: String.t()}

  Example:

    {:ok, tokens} = GraphApi.Auth.Delegated.exchange_code(
      tenant_id: "your-tenant-id",
      client_id: "your-client-id",
      client_secret: "your-client-secret",
      code: params["code"],
      redirect_uri: "http://localhost:4000/auth/callback"
    )

STEP 3: Refresh when expired

  GraphApi.Auth.Delegated.refresh_token(opts)
  @spec refresh_token(keyword()) :: {:ok, token_response()} | {:error, AuthError.t()}

  Required options:
    :tenant_id     - Azure AD tenant ID
    :client_id     - Application (client) ID
    :client_secret - Application client secret
    :refresh_token - Refresh token from previous response

  Optional options:
    :scope - Scope string

  Example:

    {:ok, new_tokens} = GraphApi.Auth.Delegated.refresh_token(
      tenant_id: "your-tenant-id",
      client_id: "your-client-id",
      client_secret: "your-client-secret",
      refresh_token: stored_refresh_token
    )


USING A DELEGATED TOKEN
------------------------

Pass the access_token option to any resource function:

    {:ok, me} = GraphApi.Users.get("me", access_token: tokens.access_token)
    {:ok, messages} = GraphApi.Mail.list_messages("me", access_token: tokens.access_token)

Or create a client and pass it:

    client = GraphApi.Client.new()
    {:ok, me} = GraphApi.Users.get("me", client: client, access_token: user_token)


AUTH PRIORITY ORDER
-------------------

The Auth middleware checks in this order:
1. Per-request :access_token option (delegated)
2. TokenStore using client credentials config
3. If neither is available, returns 401 error
