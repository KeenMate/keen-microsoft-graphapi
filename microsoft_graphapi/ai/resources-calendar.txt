CALENDAR VIEW
-------------

  GraphApi.Calendar.calendar_view(user_id, opts \\ [])
  GET /users/{user_id}/calendarView
  @spec calendar_view(String.t(), keyword()) :: {:ok, map()} | {:error, term()}
  Gets events in a date range for a user.

  Required options:
    :start_date_time - ISO 8601 start datetime string
    :end_date_time   - ISO 8601 end datetime string

  The date params are merged into the query parameters as
  startDateTime and endDateTime.

  Example:

    {:ok, %{"value" => events}} = GraphApi.Calendar.calendar_view("user-id",
      start_date_time: "2024-01-01T00:00:00",
      end_date_time: "2024-01-31T23:59:59"
    )

    # With OData query
    query = OData.new() |> OData.select(["subject", "start", "end"]) |> OData.top(50)
    {:ok, %{"value" => events}} = GraphApi.Calendar.calendar_view("user-id",
      start_date_time: "2024-01-01T00:00:00",
      end_date_time: "2024-01-31T23:59:59",
      query: query
    )

EXAMPLES
--------

    # List events
    {:ok, %{"value" => events}} = GraphApi.Calendar.list_events("user-id")

    # Create event
    {:ok, event} = GraphApi.Calendar.create_event("user-id", %{
      "subject" => "Team Meeting",
      "start" => %{"dateTime" => "2024-03-01T10:00:00", "timeZone" => "UTC"},
      "end" => %{"dateTime" => "2024-03-01T11:00:00", "timeZone" => "UTC"}
    })

    # Calendar view with date range
    {:ok, %{"value" => view}} = GraphApi.Calendar.calendar_view("user-id",
      start_date_time: "2024-01-01T00:00:00",
      end_date_time: "2024-01-31T23:59:59"
    )

    # List all calendars
    {:ok, %{"value" => calendars}} = GraphApi.Calendar.list_calendars("user-id")

    # Track event changes
    {:ok, page} = GraphApi.Calendar.events_delta("user-id")
