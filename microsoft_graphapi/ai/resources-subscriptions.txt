SUBSCRIPTIONS AND WEBHOOKS
==========================

Modules: GraphApi.Subscriptions, GraphApi.Webhook


GRAPHAPI.SUBSCRIPTIONS
----------------------

Operations on the /subscriptions resource. All have _query variants for batch.

  GraphApi.Subscriptions.list(opts \\ [])
  GET /subscriptions
  @spec list(keyword()) :: {:ok, map()} | {:error, term()}
  Lists active subscriptions.

  GraphApi.Subscriptions.get(subscription_id, opts \\ [])
  GET /subscriptions/{subscription_id}
  @spec get(String.t(), keyword()) :: {:ok, map()} | {:error, term()}
  Gets a subscription by ID.

  GraphApi.Subscriptions.create(attrs, opts \\ [])
  POST /subscriptions
  @spec create(map(), keyword()) :: {:ok, map()} | {:error, term()}
  Creates a new subscription.

  Required fields in attrs:
    "changeType"          - Comma-separated: "created", "updated", "deleted"
    "notificationUrl"     - HTTPS endpoint for notifications
    "resource"            - Resource path to watch (e.g., "users", "me/messages")
    "expirationDateTime"  - ISO 8601 datetime for expiry

  Optional fields:
    "clientState"                 - Secret string for validation
    "latestSupportedTlsVersion"   - Minimum TLS version

  GraphApi.Subscriptions.renew(subscription_id, attrs, opts \\ [])
  PATCH /subscriptions/{subscription_id}
  @spec renew(String.t(), map(), keyword()) :: {:ok, map()} | :ok | {:error, term()}
  Renews (updates) a subscription to extend its expiration.

  GraphApi.Subscriptions.delete(subscription_id, opts \\ [])
  DELETE /subscriptions/{subscription_id}
  @spec delete(String.t(), keyword()) :: :ok | {:error, term()}
  Deletes a subscription.


GRAPHAPI.WEBHOOK
----------------

Helpers for handling Microsoft Graph webhook notifications in Plug/Phoenix.

VALIDATION FLOW:
  When you create a subscription, Microsoft sends a POST with
  ?validationToken=<token> as a query parameter. Your endpoint must
  respond with 200 OK and the token as plain text.

NOTIFICATION FLOW:
  Microsoft sends a POST with JSON body containing notifications
  under "value". Your endpoint must respond with 202 Accepted
  within 3 seconds.

Functions:

  GraphApi.Webhook.classify(conn_or_params)
  @spec classify(Plug.Conn.t() | map()) :: {:validate, String.t()} | :notification
  Classifies an incoming webhook request.
  Returns {:validate, token} for validation requests, :notification otherwise.
  Accepts a Plug.Conn or a params map with string keys.

  GraphApi.Webhook.parse_notifications(body)
  @spec parse_notifications(map()) :: [map()]
  Parses notifications from a webhook request body.
  Extracts the "value" array. Each notification contains:
    "subscriptionId"  - Subscription that triggered this
    "changeType"      - "created", "updated", or "deleted"
    "resource"        - Resource path that changed
    "resourceData"    - Additional data (if included)
    "clientState"     - Client state from subscription

  GraphApi.Webhook.valid_client_state?(notification, expected)
  @spec valid_client_state?(map(), String.t()) :: boolean()
  Validates clientState using Plug.Crypto.secure_compare.
  Helps verify notifications are genuinely from Microsoft Graph.


FULL EXAMPLE (PLUG/PHOENIX)
----------------------------

    # In your controller
    def webhook(conn, params) do
      case GraphApi.Webhook.classify(conn) do
        {:validate, token} ->
          conn
          |> put_resp_content_type("text/plain")
          |> send_resp(200, token)

        :notification ->
          notifications = GraphApi.Webhook.parse_notifications(conn.body_params)

          for n <- notifications do
            if GraphApi.Webhook.valid_client_state?(n, "my-secret-state") do
              # Process asynchronously to respond within 3 seconds
              MyApp.NotificationWorker.enqueue(n)
            end
          end

          send_resp(conn, 202, "")
      end
    end


SUBSCRIPTION LIFECYCLE EXAMPLE
-------------------------------

    # Create
    {:ok, sub} = GraphApi.Subscriptions.create(%{
      "changeType" => "created,updated,deleted",
      "notificationUrl" => "https://example.com/webhook",
      "resource" => "users",
      "expirationDateTime" => "2025-04-01T00:00:00Z",
      "clientState" => "my-secret-state"
    })

    # List
    {:ok, %{"value" => subs}} = GraphApi.Subscriptions.list()

    # Renew before expiration
    {:ok, renewed} = GraphApi.Subscriptions.renew(sub["id"], %{
      "expirationDateTime" => "2025-05-01T00:00:00Z"
    })

    # Delete
    :ok = GraphApi.Subscriptions.delete(sub["id"])
